Project Overview

This repository contains the website project for Butterfield Bakery, a real independent bakery located in the Small Street Mall, Pretoria Central.

Website Goals and Objectives

Give Butterfield Bakery an easy-to-navigate, informative online presence.
Showcase the bakery's bread, pastry and celebration cake offerings.
Make it simple for customers to find store details, opening hours and location.
Provide a channel for customers to submit order and catering enquiries.
Key Features and Functionality
Five HTML pages: Home, About Us, Products, Enquiry, Contact.
Consistent header, navigation menu and footer across every page.
Semantic HTML structure (header, nav, main, section, footer).
Basic enquiry and contact forms (structure only — validation logic is added in Part 3).
Embedded maps for two locations on the Contact page.
Well-organised file and folder structure (css/, js/, html/).
